# SÈCHE

Application de suivi pour ta sèche : calories, macros, séances à la maison.

## 🚀 Lancer l'application

Ouvre directement : **https://cryptoflouze.github.io/seche-app/**

Ou télécharge `index.html` et ouvre-le dans ton navigateur.

## ✨ Fonctionnalités

- **Calories du jour** : barre de progression vers 2000 kcal, calories restantes
- **Macros** : protéines, glucides, lipides restants (objectifs : 180 / 180 / 75 g)
- **Repas** : saisie par repas (petit-déj, déjeuner, dîner, collations)
- **Mode OMAD** : case à cocher pour le One Meal A Day — tout se concentre sur un seul repas
- **Séances** : exercices du jour avec séries × répétitions, liens vidéo YouTube pour chaque mouvement
- **Poids** : enregistrement quotidien, historique des 14 derniers jours
- **Série** : compteur de jours consécutifs où tu as saisi tes calories
- **Bilan** : écart à l'objectif en temps réel
- **Sauvegarde locale** : tout reste sur ton appareil, rien n'est envoyé

## 🎯 Objectifs

- 2000 kcal / jour
- 180 g protéines
- 180 g glucides
- 75 g lipides
- Perte visée : 0,5 à 1 kg / semaine

## 🏋️ Semaine type

| Jour | Séance |
|------|--------|
| Lundi | Haut du corps (haltères) |
| Mardi | Cardio 30-40 min |
| Mercredi | Bas du corps |
| Jeudi | Cardio 30-40 min |
| Vendredi | Haut du corps (haltères) |
| Samedi | Cardio 30-40 min |
| Dimanche | Repos |
